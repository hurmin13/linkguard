## 기능 범위

- 입력 URL을 방문하지 않는 문자열 기반 검사
- 로컬 JSON 모델을 이용한 피싱 의심 점수
- 사용자가 입력한 도메인과의 호스트 소속 비교
- 20,000자 이내 텍스트, 최대 30개 링크 검사
- 오류 입력은 분석 불가로 표시하고 정상 점수와 구분
- 검증 데이터에서 민감도 실험, 최종 평가 수치는 고정

## 주요 검증

- 문자열 포함 여부가 아니라 DNS 라벨 경계로 도메인 소속 비교
- `@` 앞 사용자 정보와 실제 호스트 구분
- 국제화 도메인, IPv6, 사설 공용접미사 처리
- 지원하지 않는 스킴, 제어 문자, 역슬래시, 잘못된 포트 거부
- 입력 편집 시 이전 검사 결과 제거
- JSON 모델 추론과 원본 scikit-learn 예측의 동치성 확인
- 문자 모델의 미등록 문자 조합, 반복 문자, 대소문자 처리까지 TF-IDF 원본 예측과 비교
- 검증 슬라이더가 최종 평가 결과를 바꾸지 않는지 확인

## 평가에서 확인한 한계

정상 샘플이 모두 HTTPS이며 경로·쿼리가 비어 있는 데이터 수집 편향을 확인했습니다. 도메인 그룹 분리만으로는 이 편향이 제거되지 않아, 현재 모델을 등록 가능 도메인 문자열 특징으로 제한했습니다. 동일 도메인의 스킴·www·경로·쿼리 변형에서 특징과 점수가 같음을 회귀 테스트로 확인합니다. 이 선택은 특정 URL 경로나 정상 도메인 침해를 탐지하지 못하는 한계가 있습니다. 도메인 문자열 자체의 수집 편향은 남아 있으며 실제 사용 환경에 대한 별도 외부 검증이 필요합니다.

## 향후 개선

1. 경로·쿼리가 포함된 정상 URL을 갖춘 별도 공개 데이터로 외부 검증
2. 수집 시점 기준 평가 및 한국어 문자 사용 환경 평가
3. 현재 숫자 특징·문자 모델의 결과를 새 데이터에서도 비교
4. 충분한 독립 데이터가 확보되면 점수 보정과 불확실성 분석
5. 학내 발표 피드백을 반영한 화면 개선

실제 팀원 이름과 역할 분담은 확정된 정보로 별도 추가합니다.
