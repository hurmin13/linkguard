# LinkGuard 개발 계획

## 목표

URL 특징을 이용한 피싱 의심 분류 모델을 직접 학습·평가하고, 한국어 설명과 공식 도메인 비교를 제공하는 웹 시연 서비스를 구현합니다.

## 구현 순서

| 단계 | 작업 | 완료 기준 |
| --- | --- | --- |
| 1 | 공개 데이터 확보, 라벨·중복·형식 점검 | 데이터 출처와 전처리 결과 기록 |
| 2 | URL 파싱 및 특징 추출 | 학습과 신규 검사에서 동일한 특징 함수 사용 |
| 3 | 도메인 그룹 단위 데이터 분리 | 학습·검증·평가 간 그룹 중복 없음 |
| 4 | 로지스틱 회귀, 랜덤 포레스트 학습 | 재현 가능한 학습 코드와 검증 결과 확보 |
| 5 | Streamlit URL 검사 화면 구현 | 신규 URL 입력과 모델 출력 연결 |
| 6 | 공식 도메인 비교와 한국어 설명 | 등록 목록과의 일치 여부를 모델 출력과 구분 |
| 7 | 문자 속 링크 추출 | 한 개 또는 여러 HTTP/HTTPS 링크를 분리해 검사 |
| 8 | 민감도 비교 화면 | 검증 데이터의 오탐·미탐 변화를 표시 |
| 9 | 최종 평가와 문서화 | 최종 평가 결과, 설치·실행 방법, 시연 자료 확보 |

## 화면 계획

1. 검사 화면: URL 또는 문자 입력, 예상 서비스 선택, 검사 실행
2. 상세 결과: 모델 점수, URL 구조, 도메인 비교, 한국어 안내
3. 모델 평가: 모델별 성능, 혼동행렬, 검증 데이터 기반 민감도 비교

## 평가 원칙

- 피싱을 양성 클래스로 정하고 원본 라벨과의 매핑을 문서화합니다.
- 데이터 누수를 줄이기 위해 같은 등록 가능 도메인은 하나의 분할에만 포함합니다.
- 전처리 학습과 모델 학습은 학습 데이터만 사용합니다.
- 모델 선택과 판정 기준 조정은 검증 데이터에서 진행합니다.
- 최종 성능은 별도 평가 데이터에서 계산하며 실제 측정값만 보고합니다.
- 정상 URL을 피싱으로 분류한 오탐과 실제 피싱을 놓친 미탐을 함께 설명합니다.
- 도메인 비교 규칙은 머신러닝 판단 이유와 구분합니다.

## 시연 시나리오

| 번호 | 시나리오 | 핵심 확인 항목 |
| --- | --- | --- |
| 1 | 받은 문자에서 링크 검사 | 링크 추출, URL별 모델 결과 |
| 2 | 공식 도메인처럼 보이는 주소 비교 | 등록 가능 도메인 구분, 불일치 안내 |
| 3 | 탐지 기준 변경 | 검증 데이터의 탐지율·오탐·미탐 변화 |

## 제출 준비

- GitHub Public 저장소 주소
- 프로젝트 소개와 진행 현황
- 소스코드와 실행 방법
- 데이터 출처와 이용 조건
- 최종 결과보고서와 평가 결과
- 사용 매뉴얼 및 15분 이내 발표·시연 자료
