# LinkGuard 사용 매뉴얼

## 1. 실행

[README](../README.md)에 따라 Python 가상환경과 의존성을 설치한 후 프로젝트 폴더에서 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

브라우저에서 `http://localhost:8501`을 엽니다. 종료할 때는 실행한 터미널에서 `Ctrl+C`를 누릅니다.

## 2. URL 또는 문자 검사

1. **URL 검사** 화면을 엽니다.
2. 주소 한 개 또는 HTTP/HTTPS 링크가 포함된 문자 내용을 붙여넣습니다.
3. 알고 있는 공식 도메인이 있다면 비교 입력란에 넣습니다. 모르면 비워 둡니다.
4. 검사 버튼을 누릅니다.
5. URL별 결과와 상세 설명을 확인합니다.

본문에서 링크를 추출하는 기능은 문자 전체가 사기인지 판정하지 않습니다. 입력이 너무 길거나 링크가 많으면 화면에 표시되는 제한에 맞춰 나누어 검사합니다.

## 3. 결과 읽기

| 항목 | 의미 |
| --- | --- |
| 모델 점수 | 모델이 계산한 피싱 의심 점수. 피해 발생 확률이나 안전 인증이 아님 |
| 판정 | 현재 판정 기준과 점수를 비교한 분류 결과 |
| 실제 호스트 | 입력 URL의 접속 대상 호스트 문자열 |
| 등록 가능 도메인 | 공용 접미사 목록을 기준으로 구분한 도메인. 하위 도메인과 구분됨 |
| 공식 도메인 비교 | 사용자 입력 기준과의 일치 여부. 불일치만으로 피싱 확정 불가 |
| 구조 관찰 | 사용자 정보 구문, IP 호스트 등 URL에서 직접 관찰한 내용 |
| 분석 불가 | 형식 오류나 처리할 수 없는 입력. 낮은 위험이나 안전을 뜻하지 않음 |

비교 기준이 `example.org`이고 주소가 `https://example.org.login-check.example.com/auth`라면 등록 가능 도메인은 `example.com`입니다. 앞부분에 `example.org`라는 문자열이 있어도 해당 도메인에 속한 주소가 아닙니다. 이는 교육용 예시이며 실제 피싱 사이트라는 뜻이 아닙니다.

비교할 공식 도메인은 서비스의 신뢰할 수 있는 안내에서 확인하세요. 입력할 때 계정 비밀번호나 인증 토큰을 넣을 필요는 없습니다.

## 4. 모델 평가와 민감도

**모델 평가** 화면에서 모델별 측정 결과를 확인합니다.

| 지표 | 설명 |
| --- | --- |
| 정밀도(Precision) | 피싱으로 분류한 주소 중 실제 피싱인 비율 |
| 재현율(Recall) | 실제 피싱 중 찾아낸 비율 |
| F1 | 정밀도와 재현율을 함께 보는 지표 |
| 오탐률(FPR) | 실제 정상 주소 중 피싱으로 잘못 분류한 비율 |
| 미탐(FN) | 실제 피싱인데 놓친 주소 수 |

판정 기준을 낮추면 의심으로 분류되는 주소가 늘어납니다. 잡아낸 피싱과 정상 주소의 오탐이 어떻게 변하는지 함께 확인합니다. 판정 기준 조절 화면은 **검증 데이터**를 사용합니다. 최종 평가 데이터의 보고값은 슬라이더를 움직여 다시 선택하는 값이 아닙니다. 다만 개발 중 모델 범위를 개선하며 같은 평가 분할을 재사용했으므로 이 수치는 개발 반복 후의 내부 평가입니다. 별도의 새로운 외부 데이터 검증은 수행하지 않았습니다.

정상 샘플이 모두 HTTPS이고 경로·쿼리가 비어 있는 편향을 확인해, 현재 모델은 등록 가능 도메인의 문자열 특징만 사용합니다. 동일 도메인의 HTTP/HTTPS·www·경로 변형은 같은 점수를 받는 것이 정상입니다. 전체 URL의 사용자정보·하위 도메인 등은 별도 구조 관찰로 표시합니다. 정상 도메인 침해나 특정 경로의 악성 동작을 확인하지 않으며, 측정된 성능을 실제 운영 환경의 정확도로 해석하지 마세요.

## 5. 오류 해결

| 상황 | 확인할 내용 |
| --- | --- |
| 실행 명령을 찾을 수 없음 | 프로젝트 폴더와 가상환경 Python 경로 확인 |
| 라이브러리를 찾을 수 없음 | 같은 가상환경으로 `-m pip install -r requirements.txt` 실행 |
| 모델 파일이 없음 | `artifacts/` 파일을 함께 받았는지 확인. 재학습은 데이터 안내 참고 |
| 분석할 주소가 없음 | URL 한 개 또는 HTTP/HTTPS 링크를 입력했는지 확인 |
| 주소 형식 오류 | 공백·통제문자·역슬래시 또는 호스트 누락 여부 확인 |
| 공식 도메인 불일치 | 외부 인증·결제 서비스인지 공식 안내로 확인 |
| 단축 URL 검사 | 이 앱은 단축 주소의 최종 목적지를 확인하지 않음 |

## 6. 처리 범위

대상 URL을 실제로 열지 않습니다. 앱은 입력 문자열과 로컬 모델로 분석합니다. 공개 화면에는 실제 개인정보나 인증 링크 대신 교육용 예시를 사용하세요. 저장소에 포함된 JSON 모델을 사용하며 사용자가 올린 실행 파일이나 pickle 모델을 받지 않습니다.
